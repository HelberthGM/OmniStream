OmniStream

Tu servidor multimedia está funcionando. Prueba los endpoints desde la terminal o desde tu cliente favorito.

● Servidor activo · :8080
1

Indexar un recurso

Registra un video, imagen, audio o texto en memoria.

curl -X POST http://localhost:8080/api/recursos \
  -H 'Content-Type: application/json' \
  -d '{"nombre":"Vacaciones","rutaArchivo":"/media/v.mp4","extension":"mp4","tamanoBytes":1048576}'
2

Buscar recursos

Consulta todo lo indexado o filtra por tipo y nombre.

curl "http://localhost:8080/api/recursos"
curl "http://localhost:8080/api/recursos?tipo=VIDEO"
3

Controlar reproducción

Usa el id devuelto al indexar un recurso.

curl -X POST http://localhost:8080/api/reproduccion \
  -H 'Content-Type: application/json' \
  -d '{"idRecurso":"ID_DEL_RECURSO","comando":"REPRODUCIR"}'
